# УсЗасвар — Дуудлагын сантехникийн апп

Дуудлагын сантехникийн үйлчилгээний апп. Гурван талтай:

- **Хэрэглэгч** — үйлчилгээ үзэж дуудлага өгөх, материал захиалах, үнэлгээ/гомдол гаргах
- **Сантехникч** — нууц үгээр нэвтрэх, дуудлага хүлээж авах, coin цуглуулах
- **Админ** — бүгдийг хянах, төлбөр баталгаажуулах, блоклох, үнэ/материал засах, данс тохируулах

---

## 1. Бэлтгэл — Node.js суулгах

Энэ апп ажиллахын тулд компьютерт **Node.js** хэрэгтэй (нэг л удаа суулгана).

1. https://nodejs.org руу ор
2. **LTS** хувилбарыг татаж суулга
3. Суулгасны дараа терминал (Command Prompt / Terminal) нээгээд шалга:
   ```
   node -v
   ```
   Хувилбарын дугаар (жишээ: `v20.x.x`) гарвал зөв.

---

## 2. Апп ажиллуулах

1. Энэ фолдер (`usanzasvar-app`) -ыг компьютер дээрээ задал
2. Терминал нээгээд тэр фолдер руу ор:
   ```
   cd зам/usanzasvar-app
   ```
   (Зөвлөгөө: фолдерийг VS Code дээр нээгээд дотор нь терминал нээх хамгийн хялбар)
3. Шаардлагатай сангуудыг суулга (нэг удаа):
   ```
   npm install
   ```
4. Аппаа ажиллуул:
   ```
   npm run dev
   ```
5. Терминалд гарч ирэх хаягийг (жишээ: `http://localhost:5173`) браузераар нээ.

Болоо! Апп ажиллаж байна. Код өөрчлөхөд браузер автоматаар шинэчлэгдэнэ.

---

## 3. Анхны тохиргоо (апп нээгдсэний дараа)

1. Дээд талын **"Админ"** таб → нууц үг: **`admin123`**
2. **Тохиргоо** таб → банкны дансаа оруул (сантехникчид энэ данс руу хураамжаа төлнө)
3. **Үйлчилгээ / Материал** табаас үнэ, нэрээ өөрийн бизнест тааруул

> Админ нууц үгийг солих: `src/App.jsx` файлын дээд хэсэгт байгаа
> `const ADMIN_PASSWORD = 'admin123';` мөрийг өөрчил.

---

## 4. Өгөгдөл хаана хадгалагддаг вэ?

Одоогоор бүх өгөгдөл (захиалга, сантехникч, материал...) тухайн **браузерын localStorage**-д хадгалагдана. Энэ нь:

- ✅ Интернетгүй ажиллана
- ✅ Шууд ажиллана, тохиргоо хэрэггүй
- ⚠️ Зөвхөн тухайн компьютер/браузерт хадгалагдана — өөр төхөөрөмжид харагдахгүй
- ⚠️ Олон хүн зэрэг ажиллах боломжгүй

Жинхэнэ ажиллагаанд (олон хэрэглэгч, утсаар орох, өгөгдөл үүлэнд) → **5-р алхам**.

---

## 5. (Дараа) Supabase backend холбох

Жинхэнэ апп болгож, олон хүн зэрэг ашиглах, өгөгдлийг үүлэнд хадгалахын тулд **Supabase** холбоно. Supabase нь үнэгүй эхэлдэг, нэвтрэлт + өгөгдлийн сан + файл хадгалалтыг нэг дор өгдөг.

Үндсэн алхмууд:

1. https://supabase.com дээр төсөл үүсгэ (үнэгүй)
2. Хүснэгтүүд үүсгэ: `bookings`, `techs`, `materials`, `mat_orders`, `services`, `settings`
3. `npm install @supabase/supabase-js`
4. `src/storage.js`-ийн localStorage логикийг Supabase дуудлагаар сольж, `window.storage.get/set/list`-ийг тухайн хүснэгт рүү унших/бичих болгоно
5. Сантехникч/админ нэвтрэлтийг Supabase Auth руу шилжүүлбэл нууц үг автоматаар шифрлэгдэнэ (одоогийн demo-д энгийн текстээр хадгалагддагийг анхаар)

Энэ алхамд тусламж хэрэгтэй бол над руу хандаарай — хүснэгтийн бүтэц, холболтын кодыг бэлдэж өгье.

## Файлын бүтэц

```
usanzasvar-app/
├── index.html          # үндсэн HTML
├── package.json        # сангуудын жагсаалт
├── vite.config.js      # Vite тохиргоо
└── src/
    ├── main.jsx        # эхлэлийн цэг
    ├── storage.js      # өгөгдөл хадгалах давхарга (localStorage)
    └── App.jsx         # апп бүхэлдээ (бүх дэлгэц, логик)
```

Бараг бүх код `src/App.jsx`-д байгаа. Үнэ, дүүрэг, хураамж зэргийг файлын дээд хэсгийн тогтмолуудаас (`DISTRICTS`, `REGISTRATION_FEE`, `PER_CALL_FEE` гэх мэт) шууд засаж болно — эсвэл аппаас Админ → Үйлчилгээ/Материал/Тохиргоо хэсгээс засна.
